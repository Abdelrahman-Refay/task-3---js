
1\. What does each method do? A method is a function associated with an object that performs a specific operation.

2\. What does each method return? It depends on the method. Some return a value, while others return `undefined`.

3\. What does `pop()` return when the array is empty? It returns `undefined`.

4\. Can you change an array’s elements or an object’s properties declared with `const`? Yes. You can modify their contents, but you cannot reassign the variable to a different array or object.

5\. How is modifying a value different from reassigning the variable? Modifying changes the existing array or object. Reassigning makes the variable refer to a different value.

6\. What is the difference between a function declaration and a function expression? Can you call each before its definition? Function declarations can be called before their definition because they are hoisted. Function expressions assigned to `const` cannot be called before initialization.

7\. What is the difference between an implicit return and an explicit return? An implicit return returns a value automatically in a concise arrow function. An explicit return uses the `return` keyword.

8\. How do you return an object using an arrow function? Wrap the object in parentheses so JavaScript interprets it as an object expression.

9\. What is the difference between a parameter and an argument? A parameter is a variable defined in a function. An argument is the actual value passed to the function.

10\. What does a function return when it has no `return` statement? It returns `undefined`.

11\. Does `console.log()` return the value it displays? No. It displays the value in the console and returns `undefined`.
